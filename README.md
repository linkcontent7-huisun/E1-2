## 🧒 쉽게 말하면

> **성지순례 가기 전에 풀어 보는 퀴즈 카드 상자**를 컴퓨터 안에 만든 것이다.
> 카드를 한 장씩 뽑아 풀고, 새 카드를 넣고, 다 쓴 카드는 버린다. 프로그램을 껐다 켜도 **카드 상자와 내 최고 점수가 그대로** 남아 있다.

이 과제에서 만나는 말 여섯 개만 그림으로 기억하면 된다.

| 말 | 비유 | 이 과제에서 |
|---|---|---|
| 🧱 **클래스** | 붕어빵 **틀** | `Quiz` 틀 하나로 퀴즈 카드를 똑같은 모양으로 찍어 낸다 |
| 🥮 **객체** | 틀로 찍은 **붕어빵** | 퀴즈 10문제 = 붕어빵 10개 |
| 🗂️ **리스트 · 딕셔너리** | 카드 **상자** · 이름표 붙은 **칸** | 카드 상자(리스트) 안에 카드마다 문제·선택지·정답 칸(딕셔너리)이 있다 |
| 📒 **JSON 파일** | 누구나 읽는 **메모장 양식** | `state.json`에 카드 상자와 점수를 적어 둔다. 메모장으로 열어 볼 수 있다 |
| 🛟 **예외 처리** | 서커스의 **안전망** | 엉뚱한 글자를 치거나 파일이 깨져도 프로그램이 떨어지지 않는다 |
| 🌿 **브랜치** | 노트를 **복사해서 연습장**에 먼저 써 보기 | 연습장에서 잘 되면 원본 노트(main)에 합친다 |

## 🚶 따라 하기

모든 화면은 이 컴퓨터에서 실제로 실행한 출력이다. (전체 원본: [docs/logs/02-run-demo.md](docs/logs/02-run-demo.md))

### 1단계. 폴더로 들어가서 실행한다

압축을 푼 폴더(`E1-2`)로 이동한 뒤 실행한다.

```bash
cd E1-2
python main.py
```

맨 위에 이런 한 줄이 나오면 성공이다. 카드 상자(퀴즈 10개)를 불러왔다는 뜻이다.

```text
📂 저장된 데이터를 불러왔습니다. (퀴즈 10개, 최고점수 없음)
```

### 2단계. 아직 안 풀었을 때의 점수를 본다

`4`를 치고 Enter를 누른다. 아직 풀지 않았으니 이렇게 알려 준다.

```text
선택: 4
⚠️ 아직 퀴즈를 풀지 않았습니다. 퀴즈를 풀면 점수가 기록됩니다.
```

### 3단계. 퀴즈를 풀어 본다

`1`을 치고, 풀 문제 수(예: `3`)를 고른다. 정답은 **1~4번 숫자**로 치고, **`0`을 치면 힌트**가 나온다.

```text
선택: 1
몇 문제를 풀까요? (1-10): 3

📝 퀴즈를 시작합니다! (총 3문제)
----------------------------------------
[문제 1]
1801년 신유박해 때 박해를 주도한 왕실 인물은?

1. 정순왕후
2. 흥선대원군
3. 명성왕후
4. 인수대비

정답 입력 (힌트 보기: 0): 0
💡 힌트: 어린 임금을 대신해 나라를 다스리던 왕실 여성입니다.
정답 입력 (힌트 보기: 0): 1
✅ 정답입니다!
```

다 풀면 결과와 점수가 나온다. **힌트를 쓰고 맞힌 문제는 0.5점만** 인정되는 게 보너스 규칙이다.

```text
🏆 결과: 3문제 중 2문제 정답! (50점)
💡 힌트 1회 사용: 힌트를 쓴 정답은 0.5점만 인정됩니다.
🎉 새로운 최고 점수입니다!
```

> 문제 순서는 **매번 무작위**라서 여러분의 화면은 위와 다를 수 있다. 정상이다.

### 4단계. 내 카드를 추가한다

`2`를 치고, 문제 → 선택지 4개 → 정답 번호 → 힌트(없으면 Enter) 순서로 입력한다. 추가하면 바로 저장된다.

### 5단계. 껐다 켜도 남아 있는지 본다

`7`로 종료하고 다시 `python main.py`를 실행한다. 방금 추가한 카드와 최고 점수가 그대로 나온다.

```text
📂 저장된 데이터를 불러왔습니다. (퀴즈 11개, 최고점수 50점)
```

`6`(게임 기록)을 치면 언제, 몇 문제를 풀어 몇 점을 받았는지도 남아 있다.

```text
🗂️ 게임 기록 (총 1회, 최근 순)
2026-10-29 19:45:39  3문제 중 2문제 정답, 힌트 1회, 50점
```

### 7단계. 일부러 이상한 입력을 해 본다 (안전망 구경)

메뉴에서 `abc`, `9`, 그냥 Enter를 차례로 쳐 본다. 프로그램이 죽지 않고 다시 물어본다.

```text
선택: abc
⚠️ 잘못된 입력입니다. 1-7 사이의 숫자를 입력하세요.
선택: 9
⚠️ 잘못된 입력입니다. 1-7 사이의 숫자를 입력하세요.
선택:
```

### 8단계. 저장 파일을 일부러 망가뜨려 본다 (선택)

`state.json`의 맨 앞에 아무 글자나 하나 끼워 넣고 저장한 뒤 다시 실행한다. 프로그램이 알아채고 **기본 카드 상자로 복구**한다. 망가진 파일은 `state.json.bak`으로 옮겨 둔다.

```text

```

### 한 장의 카드 — `Quiz` 클래스 (quiz.py 일부)

```python
class Quiz:
    def __init__(self, question, choices, answer, hint=""):
        if len(choices) != CHOICE_COUNT:             # 선택지가 4개가 아니면 만들지 않는다
            raise ValueError(f"선택지는 {CHOICE_COUNT}개여야 합니다.")
        self.question = question                      # 문제
        self.choices = list(choices)                  # 선택지 4개
        self.answer = answer                          # 정답 번호(1~4)
        self.hint = hint                              # 힌트

    def is_correct(self, choice):                     # 고른 번호가 정답인지
        return choice == self.answer
```

**읽는 법:** `class Quiz`가 붕어빵 틀이고, `__init__`은 "틀에 반죽을 붓는 순간 할 일"이다. `self.question`은 "이 카드의 문제 칸"이라고 읽으면 된다.

### 입력 검문소 — `read_int` (io_utils.py 일부)

```python
def read_int(prompt, low, high):
    while True:                                       # 맞는 숫자가 올 때까지 계속 묻는다
        text = read_text(prompt)                      # 앞뒤 공백은 여기서 지워진다
        if not text:                                  # 빈 입력이면 다시
            print("⚠️ 빈 입력입니다. 숫자를 입력하세요.")
            continue
        try:
            number = int(text)                        # 글자를 숫자로 바꿔 본다
        except ValueError:                            # abc 같은 글자면 실패 → 다시
            print(f"⚠️ 잘못된 입력입니다. {low}-{high} 사이의 숫자를 입력하세요.")
            continue
        if not low <= number <= high:                 # 9 같은 범위 밖 숫자면 다시
            print(f"⚠️ 잘못된 입력입니다. {low}-{high} 사이의 숫자를 입력하세요.")
            continue
        return number                                 # 통과!
```

### 점수 계산

```text
점수 = (힌트 없이 맞힌 문제 수 + 힌트 쓰고 맞힌 문제 수 × 0.5) ÷ 푼 문제 수 × 100  (반올림)
예) 3문제 중 힌트 쓴 1개와 힌트 없는 1개를 맞히면 (0.5 + 1) ÷ 3 × 100 = 50점
```

### `state.json` 읽는 법

```json
{
  "quizzes": [ { "question": "…", "choices": ["…","…","…","…"], "answer": 3, "hint": "…" } ],
  "best_score": 50,
  "best_correct": 2,
  "best_total": 3,
  "history": [ { "played_at": "2026-10-29 19:45:39", "total": 3, "correct": 2, "hints": 1, "score": 50 } ]
}
```

| 칸 | 뜻 |
|---|---|
| `quizzes` | 카드 상자. 카드마다 문제·선택지 4개·정답 번호(1~4)·힌트 |
| `best_score` | 최고 점수(0~100). 아직 안 풀었으면 `null` |
| `best_correct` · `best_total` | 최고 점수를 낸 판의 정답 수 · 문제 수 |
| `history` | 지금까지 한 모든 판의 기록. 없어도 읽는다(예전 파일과 호환) |

위치는 프로젝트 맨 위 폴더, 글자 인코딩은 UTF-8이다.

## 🔧 트러블슈팅

실제로 겪은 오류 3건이다.

**1. 한글 콘솔에서 이모지를 찍자 `UnicodeEncodeError`**
- 문제: 메뉴 제목의 이모지를 출력하자 `'cp949' codec can't encode character '\U0001f3af'`로 종료.
- 원인 가설: 한글 Windows의 표준 출력 인코딩(cp949)이 이모지를 표현하지 못한다.
- 확인: 파이프로 실행할 때 재현, 출력 인코딩을 바꾸면 사라진다.
- 해결: `main.py`에서 `sys.stdout.reconfigure(encoding="utf-8")`. → `ca0e37a`

**2. 코드를 넣다가 줄바꿈이 깨져 `SyntaxError`**
- 문제: 셸 명령으로 코드를 넣었더니 문자열 안의 `\n`이 진짜 줄바꿈이 되어 `print(f"`가 중간에 끊김.
- 원인 가설: 셸이 `\n`을 먼저 해석한다.
- 확인: 파일의 해당 줄이 `print(f"`에서 끊겨 있었다.
- 해결: 편집 도구로 `print()`와 `print(f"…")` 두 줄로 고침. 그 뒤로는 문법 검사(`py_compile`)와 실행을 통과한 경우에만 커밋. → `e968225`

**3. UTF-8로 들어온 한글이 저장 단계에서 `UnicodeEncodeError`**
- 문제: 한글 퀴즈를 추가하고 저장하는 순간 `surrogates not allowed`로 종료.
- 원인 가설: 입력 인코딩이 cp949로 해석되어 잘못된 글자가 생기고, UTF-8 저장에서 실패한다.
- 확인: 실행 로그를 만들다가 재현. 입력도 UTF-8로 맞추자 사라졌고, 저장된 `state.json`에서 한글이 정상으로 읽혔다.
- 해결: `main.py`에서 입력도 UTF-8로 맞추고, 저장 실패는 `OSError`뿐 아니라 `ValueError`도 잡도록 수정. 브랜치 `fix/utf8-stdin`에서 고쳐 병합. → `64abb38`, 병합 `a6873ba`

## 📖 용어 사전

| 말 | 쉬운 뜻 |
|---|---|
| 터미널 | 글자로 컴퓨터에게 명령하는 창 |
| 클래스 / 객체 | 붕어빵 틀 / 틀로 찍은 붕어빵 |
| 메서드 | 클래스 안에 들어 있는 "할 줄 아는 일"(함수) |
| `self` | "나 자신"이라는 뜻의 이름표 |
| 리스트 / 딕셔너리 | 순서대로 담는 상자 / 이름표 붙은 칸 모음 |
| JSON | 프로그램끼리 주고받기 좋은 글자 메모 양식 |
| 예외 처리(`try/except`) | 실수가 나도 떨어지지 않게 받아 주는 안전망 |
| UTF-8 / cp949 | 글자를 저장하는 방식 / 예전 한글 Windows의 기본 방식 |
| Git / GitHub | 내 컴퓨터의 변경 일기장 / 그 일기장을 인터넷에 올려 두는 곳 |
| commit / push / pull | 일기 한 쪽 쓰기 / 인터넷에 올리기 / 인터넷에서 받아 오기 |
| branch / merge | 연습장에서 먼저 해 보기 / 잘 되면 원본에 합치기 |
| clone | 저장소를 통째로 복사해 내 컴퓨터로 가져오기 |
| `--no-ff` | 합친 흔적(병합 커밋)을 그래프에 남기는 옵션 |
